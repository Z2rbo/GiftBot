# 🔧 Исправление проблем PowerShell

## Проблема 1: Ctrl+C и Ctrl+V не работают

### ✅ Решение 1: Используй правую кнопку мыши
- **Копировать**: Выдели текст → Правый клик → Copy
- **Вставить**: Правый клик в PowerShell → Paste

### ✅ Решение 2: Включи быструю вставку
1. Правый клик на заголовке окна PowerShell
2. Properties → Options
3. Поставь галочку "Use Ctrl+Shift+C/V for Copy/Paste"
4. OK

### ✅ Решение 3: Используй альтернативные комбинации
- **Копировать**: `Ctrl+Shift+C` (вместо Ctrl+C)
- **Вставить**: `Ctrl+Shift+V` (вместо Ctrl+V)

---

## Проблема 2: Не переключается язык клавиатуры

### ✅ Решение 1: Используй Windows + Пробел
- Нажми `Windows + Пробел` для переключения языка
- Работает везде, включая PowerShell

### ✅ Решение 2: Настрой горячие клавиши
1. Открой Settings → Time & Language → Language
2. Нажми "Advanced keyboard settings"
3. Нажми "Input language hot keys"
4. Настрой комбинацию (например, Ctrl+Shift)

### ✅ Решение 3: Используй Alt+Shift
- По умолчанию `Alt+Shift` переключает язык
- Работает в PowerShell

---

## 🚀 Лучшее решение: Используй Windows Terminal

Windows Terminal — современный терминал от Microsoft с лучшей поддержкой клавиатуры.

### Установка:
1. Открой Microsoft Store
2. Найди "Windows Terminal"
3. Установи (бесплатно)

### Преимущества:
- ✅ Ctrl+C и Ctrl+V работают нормально
- ✅ Переключение языков работает
- ✅ Красивый интерфейс
- ✅ Несколько вкладок

## 💡 Быстрые команды для копирования

В PowerShell можно использовать команды:

```powershell
# Скопировать текст в буфер обмена
"Твой текст" | Set-Clipboard

# Вставить из буфера обмена
Get-Clipboard
```

---

## ⚙️ Настройка PowerShell для лучшей работы

Выполни эти команды в PowerShell:

```powershell
# Установить PSReadLine (улучшенная поддержка клавиатуры)
Install-Module -Name PSReadLine -Force -Scope CurrentUser

# Перезапусти PowerShell
```
