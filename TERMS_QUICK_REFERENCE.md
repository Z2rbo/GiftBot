# 📝 Быстрая шпаргалка по терминологии

## 🔤 А

**API (Application Programming Interface)**  
Интерфейс для взаимодействия между приложениями. Как меню в ресторане — видите что доступно, но не как готовится.

**Authentication (Аутентификация)**  
Процесс проверки "кто вы" (логин/пароль).

**Authorization (Авторизация)**  
Процесс проверки "что вам разрешено" (права доступа).

---

## 🔤 B

**Backend (Бэкенд)**  
Серверная часть приложения. Обрабатывает логику, работает с БД.

**Build (Сборка)**  
Процесс компиляции/упаковки кода в готовое приложение.

**Bundler (Бандлер)**  
Инструмент для объединения модулей в один файл (Webpack, Vite).

---

## 🔤 C

**CDN (Content Delivery Network)**  
Сеть серверов для быстрой доставки контента по всему миру.

**CI/CD (Continuous Integration/Deployment)**  
Автоматизация тестирования и развертывания кода.

**Cloudinary**  
Облачный сервис для управления медиа-файлами (изображения, видео).

**Container (Контейнер)**  
Изолированная среда для запуска приложения (Docker).

**CORS (Cross-Origin Resource Sharing)**  
Механизм разрешения запросов между разными доменами.

---

## 🔤 D

**Database (База данных)**  
Хранилище структурированных данных (PostgreSQL, MongoDB).

**Dependency (Зависимость)**  
Внешние библиотеки/пакеты, используемые в проекте.

**Docker**  
Платформа для контейнеризации приложений.

**Domain**  
Предметная область, бизнес-логика приложения.

---

## 🔤 E

**Endpoint (Эндпоинт)**  
URL адрес API для выполнения конкретного действия.

**Environment Variables (Переменные окружения)**  
Конфигурационные данные вне кода (API ключи, пароли).

**ES6 Modules**  
Современный способ организации модулей в JavaScript (import/export).

---

## 🔤 F

**Framework (Фреймворк)**  
Готовая структура для разработки (React, Express, Django).

**Frontend (Фронтенд)**  
Клиентская часть — интерфейс пользователя.

**Function (Функция)**  
Блок кода, выполняющий определенную задачу.

---

## 🔤 G

**GraphQL**  
Язык запросов для API, альтернатива REST.

**Git**  
Система контроля версий кода.

**GitHub/GitLab**  
Хостинг для Git репозиториев.

---

## 🔤 H

**HTTP (HyperText Transfer Protocol)**  
Протокол для передачи данных в интернете.

**HTTPS**  
Безопасная версия HTTP с шифрованием.

**Hook (Хук)**  
Функция, которая "цепляется" к определенному моменту выполнения кода.

---

## 🔤 I

**IDE (Integrated Development Environment)**  
Редактор кода с дополнительными инструментами (VS Code, Cursor).

**Integration Test (Интеграционный тест)**  
Тест взаимодействия между компонентами.

**Interface (Интерфейс)**  
Контракт, определяющий что должен делать объект, но не как.

---

## 🔤 J

**JWT (JSON Web Token)**  
Стандарт для безопасной передачи информации между сторонами.

**JSON (JavaScript Object Notation)**  
Формат данных, основанный на JavaScript объектах.

---

## 🔤 L

**Library (Библиотека)**  
Набор готовых функций для решения задач.

**Linter (Линтер)**  
Инструмент для проверки качества кода (ESLint).

**Localhost**  
Адрес вашего компьютера в сети (127.0.0.1).

---

## 🔤 M

**Middleware (Промежуточное ПО)**  
Код, выполняемый между запросом и ответом.

**MVC (Model-View-Controller)**  
Паттерн разделения кода на модель, представление и контроллер.

**Microservice (Микросервис)**  
Независимый сервис, часть большого приложения.

**Module (Модуль)**  
Отдельный файл с кодом, выполняющий определенную функцию.

**MongoDB**  
NoSQL база данных (документо-ориентированная).

---

## 🔤 N

**npm (Node Package Manager)**  
Менеджер пакетов для JavaScript.

**Node.js**  
Среда выполнения JavaScript на сервере.

---

## 🔤 O

**ORM (Object-Relational Mapping)**  
Технология связи объектов с БД (Sequelize, TypeORM).

**OAuth**  
Протокол авторизации через сторонние сервисы.

---

## 🔤 P

**Package (Пакет)**  
Готовая библиотека/модуль для использования.

**PostgreSQL**  
Реляционная база данных (SQL).

**Promise**  
Объект для работы с асинхронным кодом.

**Proxy (Прокси)**  
Промежуточный сервер между клиентом и сервером.

---

## 🔤 R

**REST (Representational State Transfer)**  
Архитектурный стиль для веб-сервисов.

**Repository (Репозиторий)**  
Паттерн для абстракции доступа к данным.

**Refactoring (Рефакторинг)**  
Улучшение кода без изменения функциональности.

---

## 🔤 S

**Service (Сервис)**  
Модуль с бизнес-логикой.

**Singleton**  
Паттерн: только один экземпляр объекта.

**Sniffer (Сниффер)**  
Инструмент для перехвата сетевого трафика.

**SOLID**  
Принципы объектно-ориентированного программирования.

**SQL (Structured Query Language)**  
Язык запросов к базам данных.

---

## 🔤 T

**Test (Тест)**  
Проверка корректности работы кода.

**TypeScript**  
JavaScript с типами данных.

---

## 🔤 U

**Unit Test (Юнит-тест)**  
Тест отдельного модуля/функции.

**URL (Uniform Resource Locator)**  
Адрес ресурса в интернете.

---

## 🔤 V

**Version Control (Контроль версий)**  
Система отслеживания изменений в коде (Git).

**Virtual Machine (Виртуальная машина)**  
Эмуляция компьютера внутри компьютера.

---

## 🔤 W

**Webhook**  
HTTP-запрос, отправляемый при наступлении события.

**WebSocket**  
Протокол для двусторонней связи в реальном времени.

---

## 🔤 X-Y-Z

**XML (eXtensible Markup Language)**  
Язык разметки данных.

**YAML (YAML Ain't Markup Language)**  
Формат данных для конфигурационных файлов.

## 🎯 Популярные комбинации терминов

**REST API** — веб-сервис, работающий по принципам REST

**JWT Token** — токен для авторизации в формате JWT

**MVC Pattern** — архитектурный паттерн Model-View-Controller

**CI/CD Pipeline** — автоматизированный процесс тестирования и деплоя

**ORM Library** — библиотека для работы с БД через объекты

**Microservice Architecture** — архитектура из независимых сервисов

---

## 💡 Полезные аналогии

**API** = Меню ресторана (видите что доступно, не знаете как готовится)

**Модуль** = Деталь конструктора (можно использовать в разных местах)

**Framework** = Фундамент дома (основа, на которой строите)

**Library** = Инструмент (молоток, отвертка — для конкретных задач)

**Database** = Шкаф с документами (хранилище информации)

**Backend/Frontend** = Кухня/Зал ресторана (кухня готовит, зал подает)

**Container** = Коробка с приложением (работает одинаково везде)

**Middleware** = Охранник на входе (проверяет перед пропуском)
