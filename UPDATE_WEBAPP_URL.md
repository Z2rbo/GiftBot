# 🔗 Как обновить URL веб-аппа в Telegram

## Шаг 1: Узнай правильный URL Vercel

1. Зайди на **vercel.com** и войди в аккаунт
2. Открой проект **GiftBot** (или как он называется)
3. В разделе **"Deployments"** найди последний деплой
4. Скопируй **URL** (должен быть вида: `https://giftbot-xxx.vercel.app` или `https://webapp-nine-navy.vercel.app`)

**Или:**
- В настройках проекта (Settings → Domains) посмотри домен
- Обычно это: `https://[имя-проекта].vercel.app`

---

## Шаг 2: Обнови URL в BotFather

### Вариант A: Через команду `/setmenubutton`

1. Открой **@BotFather** в Telegram
2. Отправь команду: `/setmenubutton`
3. Выбери своего бота из списка
4. Выбери тип: **`web_app`**
5. Введи название кнопки: **`🎮 Играть`**
6. Вставь URL (который скопировал из Vercel):
   ```
   https://webapp-nine-navy.vercel.app
   ```
   *(замени на свой реальный URL)*

### Вариант B: Через команду `/newapp`

1. Открой **@BotFather**
2. Отправь: `/newapp`
3. Выбери бота
4. Введи название: **`🎮 Играть`**
5. Вставь URL веб-аппа
6. Готово!

---

## Шаг 3: Обнови URL в Railway (переменные окружения)

1. Зайди на **railway.app**
2. Открой проект с ботом
3. Перейди в **Variables** (переменные окружения)
4. Найди переменную **`WEBAPP_URL`**
5. Обнови значение на правильный URL из Vercel
6. Сохрани — бот перезапустится автоматически

---

## Шаг 4: Проверка

1. Открой бота в Telegram
2. Нажми кнопку **"🎮 Играть"**
3. Должен открыться **правильный** веб-апп (с твоим дизайном)
4. Проверь, что все кнопки работают

---

## ❌ Если не работает:

### Проблема: Открывается старый сайт
**Решение:**
- Убедись, что URL в BotFather **точно совпадает** с URL в Vercel
- Проверь, что в Vercel задеплоен **последний** коммит из GitHub
- Очисти кэш Telegram: закрой бота полностью и открой заново

### Проблема: "WebApp not available"
**Решение:**
- Проверь, что URL начинается с **`https://`** (не `http://`)
- Убедись, что сайт доступен в браузере (открой URL в Chrome)
- Проверь, что в Vercel проект **активен** (не удалён)

### Проблема: Кнопка не появляется
**Решение:**
- В BotFather отправь `/setmenubutton` и выбери бота
- Убедись, что выбрал тип **`web_app`** (не `url`)
- Проверь, что URL правильный и доступен

---

## 📝 Быстрая команда для BotFather:

```
/setmenubutton
[выбери бота]
web_app
🎮 Играть
https://webapp-nine-navy.vercel.app
```

*(замени URL на свой реальный из Vercel)*
