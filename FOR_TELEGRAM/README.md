# 📱 ПАПКА ДЛЯ TELEGRAM

## 📋 Что здесь?

Эта папка содержит файлы, которые нужно загрузить в Telegram через @BotFather.

---

## 🖼 Файлы:

1. **bot_avatar.png** — аватарка бота
2. **BOT_SETUP.md** — инструкция по настройке

---

## 🚀 Как использовать:

### Шаг 1: Загрузи аватарку
1. Открой Telegram → @BotFather
2. Отправь: `/setuserpic`
3. Выбери своего бота
4. Отправь файл **bot_avatar.png** из этой папки

### Шаг 2: Настрой описание
1. Открой файл **BOT_SETUP.md**
2. Скопируй тексты для BotFather
3. Отправь команды из инструкции
